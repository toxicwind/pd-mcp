# Security Policy

## Scope

pd-mcp wraps **offensive security tooling** (port scanners, vulnerability scanners,
subdomain brute-forcers). It is built for authorized reconnaissance — your own
infrastructure, bug-bounty scopes, and consented assessments.

## Reporting a vulnerability

Report via GitHub's private vulnerability reporting on
[toxicwind/pd-mcp](https://github.com/toxicwind/pd-mcp/security/advisories/new).
Do not open a public issue for a live vulnerability. Response within 72 hours.

## Responsible use

Do not point these tools at systems you are not authorized to test.
Unauthorized scanning may be illegal in your jurisdiction.

## Supported versions

`main` is the supported line.
